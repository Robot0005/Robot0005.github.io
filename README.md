### HDR写真を共有できる場所がなかったので自作しました！
- 環境ある方はJPEG XL、ない方はJPEG(GainMap)でどうぞ。
- iOSのブラウザはJPEG(GainMap)に対応してますが、動作が重たいのでJPEG XL推奨。
- Windowsの方は、システム設定 ＞ ディスプレイ ＞ HDR 内の「SDRコンテンツの明るさ」を 31 に設定してください。
- スマートフォンの方は、周囲の環境光に合わせ、画面輝度を適切に調整してください。(「ホワイトポイントを下げる」などの輝度制限機能はOFFにしてください)
- HDRや、JPEG XL環境がない場合は、写真を表示できません。警告画面がでます。
